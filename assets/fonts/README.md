# Local fonts

These files are from the [Google Fonts repository](https://github.com/google/fonts) and are bundled so the practice desk works offline.

| Family | Source | License |
| --- | --- | --- |
| DM Serif Display | [google/fonts/ofl/dmserifdisplay](https://github.com/google/fonts/tree/main/ofl/dmserifdisplay) | [OFL-DMSerifDisplay.txt](OFL-DMSerifDisplay.txt) |
| Source Serif 4 | [google/fonts/ofl/sourceserif4](https://github.com/google/fonts/tree/main/ofl/sourceserif4) | [OFL-SourceSerif4.txt](OFL-SourceSerif4.txt) |
| Inter | [google/fonts/ofl/inter](https://github.com/google/fonts/tree/main/ofl/inter) | [OFL-Inter.txt](OFL-Inter.txt) |

The overview uses DM Serif Display for large headings and numerals, Source Serif 4 for reading text, and Inter for navigation and controls. Other screens retain their current type styles for now.
