# Exam 5 Practice Desk

A local study app for practicing and scoring CAS Exam 5 questions from past exams.

## Start

In this folder, run:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). Press `Ctrl+C` to stop the app. No installation or account is needed.

## Study

Choose a chapter or past exam in **Question library**, or start a quiz in **Quiz mode**. Write your answers, use the scratchpad for calculations, then reveal the sample answers and score each part. Review chapter scores in **Performance**, saved work in **Attempt history**, and missed questions in **Retry queue**.

Your work is saved in this browser. Use **Export backup** regularly; **Import backup** replaces the work currently saved in that browser.
